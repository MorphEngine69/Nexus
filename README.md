# Nexus

Storage network mod for Minecraft: disk-based storage, item/fluid/energy pipes,
automation, RF machines, filters and upgrades.

| | |
|---|---|
| Minecraft | 26.2 |
| NeoForge | 26.2.0.88 |
| Java | 25 |

## Building

```bash
./gradlew build
```

The mod jar is produced in `nexus-neoforge/build/libs`.
